# Support

Lahore Tech Events is a community-driven product. If something is unclear, an event is outdated, or a feature is not working as expected, support requests are welcome.

## Before contacting support

Please check:

- The setup and environment instructions in [`README.md`](README.md) for local development questions.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) for contribution and pull request guidance.
- [`SECURITY.md`](SECURITY.md) for security vulnerabilities. Do not post security issues publicly.
- The event's external registration page for ticketing, payment, schedule, or cancellation questions.

## What support can help with

- Account sign-in or sign-up problems.
- Incorrect, outdated, duplicate, or inappropriate event listings.
- Organizer submission and moderation-status questions.
- Broken links, accessibility problems, or unexpected product behavior.
- Documentation improvements and feature suggestions.

## How to contact us

Contact the maintainer privately through [salmanahmad.tech](https://salmanahmad.tech). Please include:

- A short description of the issue.
- The page URL or event name involved.
- Steps to reproduce the problem.
- Your device and browser, when relevant.
- Screenshots or error messages with passwords, tokens, and private data removed.

For an event correction, include the correct information and a reliable source or registration link where possible. For account issues, never send your password, authentication code, or secret keys.

## Response expectations

This is an independent community project, so support is handled as capacity allows and does not guarantee an immediate response. Urgent security concerns should follow [`SECURITY.md`](SECURITY.md).

## Feature requests

Feature ideas are welcome. Strong requests explain the user problem, who benefits, the proposed outcome, and any useful examples. Product decisions consider community value, privacy, accessibility, security, and maintenance cost.

## Event organizer support

Organizers are responsible for the accuracy of their listings and the operation of their events. Lahore Tech Events can help correct directory information, but it does not manage tickets, payments, attendee disputes, venue operations, or event cancellations.

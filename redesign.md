Redesign my existing website into a **premium light-theme tech event discovery platform for Lahore**, while preserving all existing functionality, routes, data, APIs, authentication, and backend logic.

## Design Direction

Use this visual style:

**Light Editorial × Bento Grid × Subtle Neo-Brutalism**

The website should feel like a modern startup product — somewhere between **Vercel, Linear, modern editorial websites, and a premium event platform** — but with a distinct Lahore tech-community identity.

Do NOT make it look like a generic conference website or a generic SaaS dashboard.

## Overall Visual Language

* Light-first design
* Warm off-white background rather than pure white
* Strong black/dark typography
* One primary blue accent
* Very subtle secondary warm yellow/orange accent inspired by Lahore
* Thin borders
* Very subtle shadows
* Medium/small border radius rather than excessive pill-shaped UI
* Large editorial typography
* Strong whitespace
* Clean asymmetric layouts
* Bento/grid-based content sections
* High information density without feeling cluttered
* Premium, modern, developer/startup aesthetic

Suggested palette:

* Background: `#FAFAF8`
* Surface: `#FFFFFF`
* Primary text: `#111111`
* Secondary text: `#6B7280`
* Border: `#E5E7EB`
* Primary accent: `#2563EB`
* Warm accent: `#F4B942`

Do not overuse the accent colors.

## Typography

Use a modern geometric/sans-serif typeface such as:

* Inter
* Geist
* Plus Jakarta Sans
* Satoshi

Use large, bold typography for major headings.

Example hierarchy:

"LAHORE'S TECH SCENE"

then:

"Find the events worth showing up for."

Headings should feel editorial and confident, not like generic marketing copy.

## Homepage

Completely rethink the visual hierarchy of the homepage.

### Hero

Create a large editorial hero section with:

* Small location label:
  `LAHORE, PAKISTAN · 31.5204° N`
* Large headline:
  `Discover what's happening in Lahore's tech scene.`
* Short supporting description
* Primary CTA: `Explore Events`
* Secondary CTA: `Submit Event`

Keep the hero clean and spacious.

Avoid a huge illustration or generic tech stock image.

## Event Cards

Each card should clearly communicate:

* Event image
* Event title
* Date

* Venue
* Lahore location

Use typography and spacing to establish hierarchy instead of excessive colors.

Cards can have slightly different sizes to create a Bento layout.

## Lahore Identity

Make Lahore part of the product identity, but keep it subtle and sophisticated.

Use:

* Lahore location references
* Venue/location information
* Subtle map/grid elements
* Lahore coordinates
* Neighborhood information where useful
* Local tech-community references

Do NOT use obvious clichés such as:

* Large Minar-e-Pakistan illustrations
* Pakistan flag everywhere
* Excessive green
* Traditional decorative patterns
* Tourist-style Lahore imagery

The goal is:

**"A modern tech platform built around Lahore"**

not:

**"A website decorated with Lahore."**

## Responsive Design

The design must work exceptionally well on:

* Desktop
* Laptop
* Tablet
* Mobile

On mobile, prioritize:

1. Search
2. Event discovery
3. Filters
4. Event cards
5. Registration

Do not simply shrink the desktop layout.

Create proper mobile compositions.

## Important Engineering Requirement

This is a **redesign**, not a rewrite.

Before changing anything:

1. Inspect the existing project.
2. Understand the current component structure.
3. Identify existing routes.
4. Identify existing API calls.
5. Identify authentication flows.
6. Identify database interactions.
7. Identify reusable components.
8. Preserve all working functionality.

Do not unnecessarily change backend logic.

Do not remove existing features simply because they don't appear in the new design.

Refactor components only where necessary to support the new UI.

## Final Design Goal

The final website should feel like:

**"The home of Lahore's tech community."**

It should be:

* Modern
* Light
* Premium
* Editorial
* Developer-friendly
* Community-driven
* Highly discoverable
* Visually distinctive
* Fast
* Responsive

The most important principle:

**Content and event discovery come first. Design should make finding and registering for Lahore tech events effortless.**

Do not blindly follow the existing layout. Reorganize the UI where necessary to achieve this design direction, while preserving the application's functionality and data.
